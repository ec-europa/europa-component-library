### Accessible names

If an author's picture accompanies a quote, it can be marked as decorative, as the author's name will already be displayed - describing the photo would be redundant for screen reader users.

Quotation marks are also decorative and don't need description. Screen readers will naturally announce the text as a quote, based on the proper code in the ECL Blockquote component.

### Readability

Avoid using italics for quotes to ensure better readability.

### Screen Reader Support

When a quote is in a different language from the surrounding page (e.g., a quote in English on a French language page), identify the quote's language. This allows screen readers to adapt their pronunciation. Developers need to be informed of these 'foreign' content chunks, as they cannot read all content or easily identify language changes themselves; editors must mark them.
