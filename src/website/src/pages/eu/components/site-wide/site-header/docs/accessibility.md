### Accessible names

The language switcher is described for blind users as: "Change language, current language is English - EN".

The abbreviation at the end matches the desktop display. It's crucial to include this visible label within the accessible name so sighted users navigating by voice (due to severe motor impairment) can activate the button by pronouncing the abbreviation they see.

The search icon is described for blind users as: "Search".

The hamburger icon is described for blind users as: "Menu".
