The Page header component ensures that users are met with a familiar design layout, as well as a content pattern through which information about the current page is presented. It is always placed just below the [Site header](https://v5-dev--europa-component-library.netlify.app/ec/components/site-wide/page-header/usage/).

The component is available in a positive and a negative version. Harmonised and standardised websites must use the positive version (the negative one is used on the EC corporate site only). The Page header elements are optional - depending on the page, rather than the site/template type.
