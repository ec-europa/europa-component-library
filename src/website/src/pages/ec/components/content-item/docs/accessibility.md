### Accessible names

Typically, the optional content item image is decorative and doesn't need a description. However, if the image contains text not repeated in the surrounding visible text, it must be described, as it provides unique content.

The list of labels has a specific visual style. For blind users, this style is conveyed via a hidden text read by screen readers before the visible labels. This defaults to "labels," but can be customised if needed.

The calendar and pin icons do not need descriptions, as the subsequent content (a date and location) is sufficiently intuitive.

### Accessible date blocks

Cancelled events may have a specific visual style. This visual information is not conveyed to blind users. Ensure the event's mention explicitly states its cancellation (e.g., in brackets or with a textual tag).
