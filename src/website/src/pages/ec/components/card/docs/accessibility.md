### Accessible names

Most card images are decorative and don't need a description. However, if a card image contains text not repeated in the card title or description, it must be described, as it provides unique content.

The list of labels has a specific visual style. For blind users, this style is conveyed via a hidden text read by screen readers before the visible labels. This defaults to "labels," but can be customized if needed.
