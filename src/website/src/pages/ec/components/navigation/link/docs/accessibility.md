### Accessible names

The icon indicating a link to an external domain is described to blind users as: "Link to an external domain."

For standaloline links with icons, make sure to describe the icon to blind users.

Follow these best practices when selecting words for links:

- Choose words that make the link intuitive out of context. Is the link clear enough on its own to guess the target page?
- Avoid linking meaningless terms like "here," "website," or "link"
