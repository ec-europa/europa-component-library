### Accessible names

The gallery is described to blind users as: "Open gallery items to view images in original size, watch videos, and share them." If your gallery's functionalities differ, update this generic description.

Each image and video thumbnail must be described to blind users. Refer to the Media Container component for more details.

In the zoomed dialog, the carousel arrows have the descriptions: "Previous" | "Next".
